# Cadet Solutions

This is a repository where different cadet solutions to <A/C_> challenges go.


## Want to contribute?

Speak to an MC to see if your solution is different enough from other cadet solutions on the repo. 

- Pull the latest changes from this repo to your local repository
- Add your project to the specified folder
- Change the project name to your full name. eg: christina-hinchin.java

So, if you are contributing to the Closest Neighbours exercise, your file should be placed in:

`java-exercises/closest-neighbours/christina-hinchin.java`

- Add and commit, make sure your commit message states the exercise and your name: 'closest neighbours: christina hinchin'
- Push to this repository!

## Want to comment?

Is there an implementation you don't understand? Leave them a comment!

- Click on `commits` and find the commit message of the person whose contribution you wish to comment on.
- Scroll down to the text box and leave a comment

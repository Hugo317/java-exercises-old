# Class Presentations

This is where your homeworks and summarizer pdfs go!

## How to contribute?

- Pull the latest changes from this repository to your local repository
- Make sure your filename follows the proper format
-- HOMEWORK: year_month_day_name_theme.pdf
-- SUMMARIZER: year_month_day_name.pdf
- Add to the appropriate folder
- Commit with a message that states either the homework theme or summarizer day
- Push to this repository
